# Мета
Оволодіння навичками побудови професійної об'єктно-орієнтованої моделі в Python, що базується на принципах SOLID, використанні абстрактних класів, протоколів, дженериків та системи статичної типізації.

## Опис алгоритму (Варіант №3)
Проєкт реалізує систему інтернет-магазину (Store Catalog). 
1. **Domain Entities**: Створено класи `Product`, `Category`, `InventoryItem`, `StoreCatalog`.
2. **Value Objects**: Клас `Price` реалізовано як `frozen` dataclass з валідацією через `__post_init__` та оператором додавання `__add__`.
3. **Abstraction & SOLID**: 
    - Використано `ABC` (`Discount`) для поліморфізму стратегій знижок.
    - Використано `Protocol` (`PricingStrategy`) для структурної типізації поведінки цін.
    - `StoreCatalog` використовує Dependency Injection для роботи з `Repository`.
4. **Generics**: Клас `Repository[T]` дозволяє керувати різними типами сутностей, дотримуючись принципу `DIP` (Dependency Inversion Principle).
5. **Type Safety**: Код використовує `Type hints` для всіх публічних методів. Дані ззовні можна обробляти через `TypedDict` (`ProductData`).
6. **Encapsulation**: Доступ до ціни реалізовано через `@property`, що дозволяє контролювати стан об'єкта.

## Висновок
В процесі виконання лабораторної роботи було створено гнучку архітектуру, де логіка розподілена між доменом, сервісами та інфраструктурою. Використання статичного аналізатора (mypy) дозволило виявити потенційні помилки типізації до етапу виконання. Композиція (`StoreCatalog` має `Repository`) виявилася ефективнішою за жорстке успадкування, що відповідає принципам SOLID, зокрема ISP та DIP.
